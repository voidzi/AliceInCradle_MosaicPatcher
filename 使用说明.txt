MosaicPatcher v1.1  使用说明
==========================================================

作用
----
一键关闭 Alice in Cradle 的马赛克显示。

    原来  ->  有马赛克
    改后  ->  无马赛克

程序会自动找到游戏的 Assembly-CSharp.dll，只做一处极小的改动：
文件长度完全不变、其余内容一个字节都不动，首次处理时自动备份，随时可一键还原。


运行（三种方式，任选一种）
--------------------------
方式一【推荐 · 真单文件】双击   MosaicPatcher.exe
        只有 60 KB，用 C# 编写。
        * 不需要安装 Python
        * 不自解压（不会往临时目录写东西，不会卡住）
        * 只依赖系统自带的 .NET Framework 4.8（Win10/11 都有）

方式二【零系统提示】双击   运行.bat   （等价于双击 MosaicPatcher.pyw）
        用你已安装的 Python 运行。python.exe 是官方签名的程序，
        Windows 不会弹"无法识别的应用"，也基本不会被杀软误报。

方式三  进入 MosaicPatcher_portable 文件夹，双击 MosaicPatcher_portable.exe
        早期用 PyInstaller 打的包（25 MB，自带 Python 运行时）。
        现在已被方式一取代，不需要的话整个文件夹可以删掉。

三种方式功能完全一样，改出来的结果字节完全相同（可交叉使用：
A 方式改的，B 方式能正确识别状态与还原）。


关于 Windows 提示"无法识别的应用 / 发布者未知"
-----------------------------------------------
原因：exe 没有正式的代码签名证书（微软只信任从 CA 买的证书），
      Windows 的 SmartScreen 会按"信誉"拦截未签名程序。三种方式里，
      方式一/三会被拦一次，方式二不会（它跑在已签名的 python.exe 里）。

处理办法（任选）：
1) 【最省事】用方式二：双击 运行.bat，完全没有提示。
2) 【放行一次】弹窗上点「更多信息」→「仍要运行」；之后一般不再问。
   或到  设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 →
   基于声誉的保护，关闭「检查应用和文件」（或把本文件夹加入排除项）。
3) 【说明】想彻底消除这个提示，只能购买正式的代码签名证书（约 ¥700-2500/年）；
   自签名证书无效 —— 它看的是微软云端的信誉，不是本机是否信任。


界面操作
--------
1. 程序一打开会「自动搜索」一次，找到就直接载入；找不到会提示。
   也可以随时点「自动搜索」重新搜索，或点「选择文件…」手动选。
2. 中间状态区显示：
       - 目标文件路径、相对路径、路径形态校验
       - 文件大小、MD5
       - 方法是否定位成功、Method RVA、IL 位置
       - 当前状态：有马赛克 / 无马赛克
       - 配置文件、备份文件的状态与 MD5 校验结果
3. 点「执行去马赛克」→ 确认 → 自动备份并修改。
4. 想恢复原状，点「还原备份」。
5. 「刷新状态」重新读盘；「打开所在目录」在资源管理器里打开 DLL 所在文件夹并选中它。
   它有多级兜底：explorer 定位 → Shell COM 打开 → ShellExecute 打开 → 复制路径弹窗。
   如果检测到当前进程是「低完整性」，会直接跳过前面几种、只复制路径
   （低权限进程调用 explorer 会报 0xc0000142）。
6. 状态区最下面会显示「运行环境」（权限 / 完整性级别 / 会话），排查问题时
   可以把这几行发给我。如果显示「完整性=低 Low」，说明本目录被打上了限制标签，
   右键以管理员身份运行「修复完整性标签.bat」即可恢复。

未选择文件时，程序不会去读任何配置文件（不会猜路径）。


自动搜索规则
------------
搜索范围（相对本程序所在目录）：
  1) 程序目录自己            -> .\AliceInCradle_Data\Managed\Assembly-CSharp.dll
  2) 上一级目录（只找 1 层） -> ..\AliceInCradle_Data\Managed\Assembly-CSharp.dll
  3) 程序目录下的所有子目录（递归遍历）

判定条件（很重要）：
  只有路径形如   ...\AliceInCradle_Data\Managed\Assembly-CSharp.dll
  的文件才算数。别的目录下随便一个同名 Assembly-CSharp.dll 会被直接忽略。

多个候选时：启动时默认选优先级最高的（程序目录 > 上一级目录 > 子目录）；
点「自动搜索」会弹出列表让你自己挑。
手动选到不符合上述路径形态的文件时，会先弹确认框提醒。

例：本程序放在
    E:\...\AliceInCradle_ver030h\MosaicPatcher\
则自动搜索会命中
    ..\AliceInCradle_Data\Managed\Assembly-CSharp.dll


会生成哪些文件（都在 DLL 同目录）
--------------------------------
1. 备份文件
       Assembly-CSharp.dll.mosaicpatch.bak
   第一次执行去马赛克时自动创建；以后不会覆盖它，保证它始终是最初的原始文件。

2. 配置文件
       mosaic_patcher.json
   内容示例：
       {
         "backup_file":   "Assembly-CSharp.dll.mosaicpatch.bak",
         "backup_created": true,
         "backup_md5":    "E1F9EE52B6F9FB6668887B792451BB4D",
         "original_md5":  "E1F9EE52B6F9FB6668887B792451BB4D",
         "patched_md5":   "CB199EE7210F38B7973771318D0DE0D9",
         "state":         "patched",          // 或 "restored"
         "updated_at":    "2026-10-01 21:25:36"
       }

配置放在 DLL 所在目录，所以同一个程序拿到别的目录去用也不会串。


MD5 校验是怎么用的
------------------
* 「备份校验」= 配置里记录的 backup_md5 与备份文件当前实际的 MD5 比对：
      一致      -> 备份未被改动
      不一致    -> 备份已被改动（会明确提示）
* 「完整性」= 当前 DLL 的 MD5 与配置里记录的 patched_md5 / original_md5 比对，
  用来判断这个 DLL 是不是被本程序改过、或者被别的程序动过。
* 备份被改动过时，「还原备份」会先警告，确认后才强制还原。


命令行模式（方便脚本化 / 排查）
------------------------------
    MosaicPatcher.exe --find [--base <目录>]   自动搜索并列出候选
    MosaicPatcher.exe --status  <dll>          只看状态
    MosaicPatcher.exe --patch   <dll> [--no-backup]
    MosaicPatcher.exe --restore <dll> [--force]
    MosaicPatcher.exe --gui-selftest           界面自检
    MosaicPatcher.exe <任意命令> --out <文件>   把输出写进文件
（Python 版把 MosaicPatcher.exe 换成 python MosaicPatcher.pyw 即可）


注意事项
--------
* 修改前请完全退出游戏，否则 DLL 被占用会写入失败（程序会提示）。
* 即使 DLL 正被其它程序占用（例如杀毒软件正在扫描、或游戏没退干净），程序也会自动改用
  「把旧文件改名移开 + 新文件就位」的替换方式写入（就是资源管理器"替换"的原理，
  不需要目标文件可写），失败会自动回滚，不会损坏原文件。
* 不要删除 .mosaicpatch.bak，还原就靠它。
* 程序只会改那 1 个字节，其余内容一个字节都不动；改完文件大小与原来相同。
* 如果换了游戏版本/DLL，程序会重新自动定位；定位失败会明确报错并且不做任何修改。


关于打包 / 重新打包
------------------
MosaicPatcher.exe（推荐版）用 .NET Framework 自带的 csc.exe 编译，源码在
    _build\cs\MosaicPatcher.cs
重新编译：
    C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe ^
        /platform:anycpu /optimize+ /codepage:65001 /win32icon:_build\icon.ico ^
        /out:MosaicPatcher.exe /reference:System.dll /reference:System.Core.dll ^
        /reference:System.Drawing.dll /reference:System.Windows.Forms.dll ^
        _build\cs\MosaicPatcher.cs

MosaicPatcher_portable\（PyInstaller 版）用 PyInstaller 6.22.3 + Python 3.14.5 打包：
    python -m pip install pyinstaller
    python -m PyInstaller --noconfirm --clean --onedir --windowed ^
        --name MosaicPatcher_portable --icon _build\icon.ico ^
        --distpath . --workpath _build\work --specpath _build\spec ^
        MosaicPatcher.pyw

_build 文件夹里放着两个版本的源码、图标和辅助脚本，不需要的话可以整个删掉
（其中 tmp 子目录在本机可能因权限原因删不掉，是 0 字节的空目录，留着无影响）。
